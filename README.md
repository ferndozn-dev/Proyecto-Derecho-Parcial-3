# Proyecto Derecho Parcial 3
El proyecto consiste en desarrollar el Sistema de Evaluación de Inclusión Digital (SEID), un sitio web interactivo que permite identificar el nivel de brecha digital en estudiantes de educación básica. El sistema evalúa tres aspectos principales: si el estudiante cuenta con un dispositivo, si tiene acceso a Internet y cuáles son sus habilidades digitales. Con las respuestas, el sitio genera un diagnóstico y sugiere una acción para atender la problemática.

El proyecto busca ayudar a docentes, directores y autoridades educativas a detectar las principales necesidades tecnológicas de los estudiantes y tomar mejores decisiones para reducir la brecha digital. Para desarrollarlo se utilizaron HTML, CSS y JavaScript, convirtiendo el programa realizado anteriormente en Python en una plataforma web funcional.
